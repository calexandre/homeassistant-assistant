Install

Installing gets the latest version, v__PLUGIN_VERSION__. You need Home Assistant 2026.11 or later, Python 3, and one client: Claude Code, GitHub Copilot CLI, or VS Code with GitHub Copilot.

  1. Turn on the MCP server in Home Assistant

    Go to Settings → Devices & services → Add Integration and add Model Context Protocol Server. Then pick the entities the agent may see under Settings → Voice assistants → Expose.

    The HTTPS address set as the Internal or External URL in Home Assistant. It fills in the commands below and never leaves this page.

  2. Add the plugin and connect it

    Claude Code

    Terminal
    claude plugin marketplace add calexandre/homeassistant-assistant
claude plugin install homeassistant-assistant@homeassistant
claude mcp add --scope user --transport http homeassistant https://YOUR-HOME-ASSISTANT/api/mcp
claude mcp login homeassistant

    claude mcp login opens your browser to sign in to Home Assistant, so there is no token to copy.

    GitHub Copilot CLI

    Terminal
    copilot plugin marketplace add calexandre/homeassistant-assistant
copilot plugin install homeassistant-assistant@homeassistant
copilot mcp add --transport http homeassistant https://YOUR-HOME-ASSISTANT/api/mcp

    Copilot CLI opens your browser to sign in to Home Assistant, so there is no token to copy.

    VS Code

    Terminal
    git clone https://github.com/calexandre/homeassistant-assistant.git
code homeassistant-assistant

    The skills and the SSH guard load from the clone. Run MCP: Add Server, choose HTTP, enter https://YOUR-HOME-ASSISTANT/api/mcp, use the ID homeassistant, and sign in when VS Code opens your browser.

  3. Check that it works

    Ask a question only your house can answer:

    Prompt
    Which lights are on right now?

    The answer should name your real entities. For automations, logs, and your own home map, add the optional SSH snapshots. Stuck? See Troubleshooting.
